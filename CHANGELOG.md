# Changelog

All notable changes to this project are documented here.

## 0.1.0 (2026-11-24)

- Initial release.
- Local JSON catalogue of flats/properties with search by province, town and street.
- `add`, `list`/`search`, `webs`/`urls`, `stats` and optional `fetch` commands.
- Table, JSON and CSV output.
- Catalogue of real-estate websites with configurable search URL templates.
- Automated tests and verification script.
- zip and deb release artifacts.
- Bidirectional GitHub ⇄ GitLab mirror via GitHub Actions and GitLab CI.
- Mirror scripts also compare and replicate tags (fixed after release verification).
- Didactic guide in Spanish and English.
